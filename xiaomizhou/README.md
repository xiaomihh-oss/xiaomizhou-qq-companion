# 小米粥 · 有人设、有记忆、有成长的 QQ 陪伴机器人

Python 3.10+。使用 QQ 官方机器人 SDK、兼容 Chat Completions 的模型接口和本地 SQLite。

## 快速启动

解压后在本目录打开 PowerShell：

```powershell
python -m pip install -r requirements.txt
python start.py
```

启动方式选 `1` 为终端试聊，选 `2` 为 QQ 单聊。根据向导填写模型完整地址、模型ID和自己的API Key；QQ模式另需自己的机器人AppID和AppSecret。密钥隐藏输入，仅保留当前进程内存，不自动保存。

如果安装连接失败，可尝试：

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

没有模型凭据也可启动模式1，模型地址处回车跳过，先体验记忆和成长指令。普通聊天此时不可用，不会伪造AI结果。

QQ模式须先在 https://q.qq.com 创建官方机器人，配置开发体验用户，使用平台允许的单聊入口添加机器人。当前通过WebSocket收事件，不需填写公网回调地址。实际权限以账号后台为准。保持程序和网络在线，关机后无法回复；尚未部署云端。

## 模型配置示例

本次实测使用 DeepSeek。完整接口地址 `https://api.deepseek.com/chat/completions`，模型ID `deepseek-flash`。模型可用性与价格以服务商为准。模型Key与QQ AppSecret不能混用，切勿提交真实凭据。

## 三分钟体验

```text
/帮助
/记住 喜欢的运动=篮球
/新对话
我喜欢什么运动？
/记忆
/忘记 喜欢的运动
我喜欢什么运动？
/完成 今天读了十页书
/成长
```

普通聊天可能提出附原话依据的记忆建议；输入 `/确认记忆` 才保存，`/取消记忆` 放弃。建议30分钟失效，新话题也会取消旧建议。临时记忆7天到期，属于固定TTL，不是自然语言日期解析。`/清空` 删除当前用户本地记忆、近期对话、待确认建议与成长记录。

## 实现与边界

- companion.py：角色提示词、命令、模型请求、错误提示。
- memory.py：记忆确认、原文依据、时效、轻量中文片段匹配检索，最多8条。没有向量检索，可能漏召回。
- qq_bot.py：官方SDK单聊收发、连接回调、进程内重连状态。
- start.py：交互式配置入口。
- SQLite：按终端用户或QQ会话隔离。近期保存12条消息。

成长按用户自报完成的小事计数：3件发芽，7件成树；相同文本不重复计数。角色仍采用精灵与植物成长设定，名称为小米粥。成长不是模型训练，没有立绘进化或语音功能。

删除记忆会清除近期上下文，避免从历史重新读入。删除不影响备份或模型服务商留存。聊天上下文和被检索记忆会发送给所配置的模型服务。自动提取是模型建议，过滤不保证完美，需要用户确认。

测试：`python -m unittest -v`。自动化使用模拟网络，不代替真实QQ、真实模型评测。QQ收发已由作者试用，自动记忆的真实模型效果仍需进一步记录。没有声称已验证长期用户留存。
